results_evidence · 结果与证据链

模块位置：backend/app/modules/results_evidence/。管「跑出了什么 + 拿什么证明」：CaseResult / StepRun / Artifact / EvidenceObject / FailureCluster，以及证据中心检索与导出、审计检索。

1. 结果三件套

对象内容要点
CaseResult用例级结果（outcome、is_partial、normalized_summary、数据分级）唯一约束 (org, run, case, attempt_seq)；外部 CI 分片用 chunk_key 去重
StepRun步骤级（action、assertion_results、observation_ref、token_usage）agent 步骤只存 tool + args_hash，无参数原文（脱敏纪律）
Artifact制品元数据（object_key、checksum、kind、classification）大二进制不进 PostgreSQL；正文在本地卷（M0/M3 无 MinIO）

2. 引用 ≠ 授权（G5 铁律）

object_key / artifact_id / content_ref 永远不是下载令牌。唯一浏览器下载通道是后端代理：
GET /api/v1/artifacts/{artifact_id}/content            # API-221，每次重验租户/RBAC/分级/checksum
GET /api/v1/export-packages/{receipt_id}/content       # API-223，仅 status=succeeded 且 tester+
# Restricted 正文：代理路径直接 403 HT-POL-001，永不预签名/302

3. EvidenceObject 与证据中心（P20）

{"claim": "登录接口 5xx",                       # 结论陈述（Confidential 最小化）
 "source_object": {"connector": "jira", "resource": "...", "timestamp": "..."},
 "content_ref": "<object_key>",                # 稳定引用，非令牌
 "subject_type": "case_result", "subject_id": "...",
 "data_classification": "Confidential"}
  • append-only：EvidenceObject 禁止原地覆盖（还有 AuditEvent / GateEvaluation / AIInvocationLog / 已发布 SkillVersion）。
  • API-026/027 检索与详情（Sess，项目四角色；无法解析项目归属的组织级证据仅 owner/admin）；subject_type+subject_id 必须成对传。
  • API-028 导出受理（202 + 回执）→ 后台打包（zip/md/json，只物化元数据，Restricted 整单拒绝）→ 完成后 API-223 代理下载。受理回执与 SSE 都 ≠ 导出完成（AC-096）。

4. 失败聚类（FR-06/07）

  • 终态 run 有 failed CaseResult → 自动调度 A2 聚类：failure_clusters（category 七值枚举 / confidence / blocking_judgment / evidence_refs / unclustered_refs）。
  • AI 降级时走规则聚类（confidence 0.3，AIInvocationLog.result=degraded）——平台功能不受影响，只是 AI 增强降级。
  • 人工修正走 API-132（留 correction_history 历史留痕）；相似失败 API-133。
  • 定位器自愈（FR-10）：locator_stale 簇 → A3 建议（confidence ≥ 0.7 才可应用）→ heal_apply 审批 → 新 TestCaseVersion。

5. 本地卷对象存储

# object_store.py：确定性 object_key + 路径安全 + checksum
key = generate_object_key(organization_id=..., artifact_id=..., filename="trace.zip")
checksum = write_bytes(object_key=key, data=data)     # sha256 落库
assert verify_checksum(key, checksum)                  # 下载前必验，不符 → HT-VAL-003

6. 审计检索（P24）

AuditEvent append-only，API-024 全字段检索（actor / request_hash / approval / resource / external_request_id…）。副作用动作的关键节点都会写审计——「每个副作用可归因」是产品原则。
