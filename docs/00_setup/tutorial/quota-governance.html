quota_governance · 配额与预算

模块位置：backend/app/modules/quota_governance/。管「花多少、占多少」：组织级 OrgQuota（AI token 预算 + 执行资源配额）。

1. OrgQuota 字段

字段含义谁消费
token_budget / token_reserved / token_consumedAI token 预算与占用LLM 工厂每次 invoke 前检查；耗尽 → HT-QUOTA-001（不调模型）
executor_slot_quota执行 slotTestRun 受理
perf_concurrency_quota / perf_concurrency_in_use压测并发预算与当前占用perf worker VALIDATING 占用（row lock），终态释放

2. 使用姿势（跨模块走 port）

# 占用：with_for_update 行锁，不足返回 False（调用方落 FAILED/429）
reserved = await quota_command.reserve_perf_concurrency(session, organization_id=...)
# 释放：终态路径调用，max(0, in_use - slots) 幂等
await quota_command.release_perf_concurrency(session, organization_id=...)
# 投影：API-018 quota-view / API-017 org-quotas/current 返回配额与 in_use
exhausted = await quota_query.token_budget_exhausted(session, organization_id=...)
  • 检查在受理/派发时，不在前端；前端只显示余量提示（quota_hint），权威扣减在命令侧。
  • 超限错误码：HT-QUOTA-001（资源/预算不足，可条件重试）、HT-QUOTA-002（导出/打包类超限）。
