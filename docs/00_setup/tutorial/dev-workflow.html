开发工作流与仓库红线

本页汇总日常开发必用：分支/提交规范、测试与验证、错误码、以及 20 条红线速查。

1. 分支与提交

feat|fix/<slug>      # 代码分支；里程碑级可用 feat/M3 这类粗粒度分支
<type>(<scope>): <中文祈使句 ≤72 字，不加句号>
# type ∈ feat fix docs style refactor test chore perf ci build revert
# 例：feat(backend): 落地压测编排与性能基线（FR-11）
# 依赖锁文件（uv.lock / package-lock）变更必须独立成 commit
# pre-commit（含 gitleaks）必须通过；禁止 --no-verify

2. 验证命令（合入前必须真跑、零失败）

cd backend  && uv run ruff check . && uv run ruff format --check . && uv run mypy app && uv run pytest
cd frontend && npm run lint && npx tsc --noEmit && npm run build && npm run test
测试要求说明
service/domain 新函数至少 1 条正例；含分支或外部调用再加 1 条异常路径
API 端点至少 1 条 happy-path（httpx AsyncClient，见 tests/）
修 bug先写复现测试再修

4. 红线速查（全 20 条见根 AGENTS.md §7）

① 秘密/.env 值/PII 不入仓库、日志、Prompt。② 冻结文档改动需 change_log + 用户批准 + 展示 diff。③ 验证零失败才可提交，禁止 --no-verify。④ 新依赖需批准+审计+落锁，锁文件独立 commit。⑤ 禁 pip/poetry/pnpm/yarn。⑥ 不硬编码配置。⑦ 前端不直连外部系统、凭证不落 localStorage。⑧ 前端不推演状态机/门禁/幂等键。⑨ Restricted 不进日志/Trace/Artifact/错误体。⑩ AI 必经 AIInvocationLog，业务模块禁连模型厂商。⑪ Agent 结果不进门禁；L2+ 必须审批。⑫ SSE 不是命令通道；禁 WebSocket/GraphQL/gRPC；未到期不启用 MinIO/Redis/Temporal/Vault。⑬ 不删 Starlette 显式依赖；禁 React Router loader/action；shadcn 保持源码内置。⑭ 不新增第 24 对象 / P26+ / 未登记编号。⑮ 不自行裁决 [CONFLICT]。⑯ 禁止对 unknown 盲重试。⑰ 跨租户 404、无租户拒绝。⑱ MCP 三份清单一致。⑲ docs/ 阶段目录结构不动。⑳ 切片合入前回写 Stage 10 进度。

5. 切片工作流（本仓库的实际节奏）

1. 领切片：ai_context.md §4 里程碑表（S-Mx-yy，状态 未做）
2. 读契约：prd（US/FR/AC）→ problem_model（对象/状态机）→ api_spec（端点）→ data_model（表）
3. 出 Plan：目标/不做/文件/步骤/验证 → 用户确认
4. 实现：先契约后代码；跨模块只走 query/command port（返回 dict，不借 ORM）
5. 验证：双端四连命令全绿
6. 回写：ai_context.md 状态列（未做/部分完成/完成）+ context/mN.md 要点与残留
7. 提交：type(scope) 中文祈使句；推送后按里程碑 --no-ff 合回 main

6. 数据库迁移

# backend/alembic/versions/0001…0025，命名：序号_主题.py
# revision 链必须单线；新表建在对应模块 schema 下（如 release_orchestration）

uv run alembic upgrade head

7. 代码入口速查（全局设施）

后端路径相对 backend/app/。各业务模块的入口在各篇教程末尾的速查表。

关注点入口
应用装配main.py create_app()（注册 TraceIdMiddleware、异常处理器、api_router；lifespan 退出 dispose_engine）；api/router.py api_router 聚合 12 个模块 router（均 prefix="/api/v1"）
错误信封与错误码（§3）core/errors.py：error_envelope(...) 与约 25 个错误码工厂（unauthenticated / forbidden / policy_deny / hmac_failed / four_eyes_violation / quota_exceeded / version_conflict / idempotency_conflict…）；register_exception_handlers(app)
trace_id / 日志core/middleware.py TraceIdMiddleware.dispatch；core/logging.py configure_logging / log_with_trace
数据库与配置core/db.py：get_engine / get_session_factory / get_db_session（FastAPI 依赖）；core/config.py get_settings()（pydantic-settings，只从 .env 注入）
每请求鉴权依赖api/deps.py：require_session / require_api_token(required_scope=...) / require_session_or_token_read（Policy Gate 在 modules/approval_policy/policy_gate.py）
跨模块协作各模块 command_port.py / query_port.py（返回 dict，禁止 import 他模块 ORM）——规范见第 5 节切片工作流第 4 步
测试backend/tests/（pytest + httpx AsyncClient）；frontend/src/pages/*.test.tsx（Vitest + Testing Library）
