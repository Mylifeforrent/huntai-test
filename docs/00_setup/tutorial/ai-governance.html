ai_governance · AI 治理与 Copilot

模块位置：backend/app/modules/ai_governance/。管「AI 怎么被调用、被记账、被约束」：LLM 工厂（唯一出口）、AIInvocationLog、ModelRoute、A1 生成、Copilot（A6）。

1. LLM 工厂：AI 的唯一入口

output = await invoke(session, InvokeInput(
    organization_id=..., user_id=..., task_type="general",
    prompt_version="copilot-a6@1.0.0",      # Prompt 契约版本化
    capability_id="A5",                     # A1–A8 能力编号
    module="release_orchestration",         # 来源模块
    copilot_session_id=...,                 # Copilot 会话关联（可空）
    data_classification="Confidential"))
# output: log_id / result(ok|refused|degraded) / model / usage / cost / latency
  • 业务模块禁止直连模型厂商；每次调用写 append-only AIInvocationLog（无 Prompt 列，input_ref 仅为脱敏 object_key）。
  • invoke 前检查 kill switch（A1–A8 能力级 / 模块级 / 全局）与 token 预算；受限 → result=refused（结构化，不是异常）。
  • Restricted 内容默认禁止出站；本地模型或拒绝处理。

3. Copilot 最小版（FR-16 / P18）

POST /api/v1/copilot-sessions                       # 191 创建（tester+；viewer 拒；技能指针 M4 前拒）
GET  /api/v1/copilot-sessions                       # 190 仅本人会话
POST /api/v1/copilot-sessions/{id}/messages         # 192 A6 提问：
  kill switch（copilot 模块 / A6 能力关停）→ 403 HT-POL-001   # 命令真实失败，不是藏按钮
  token 预算耗尽 → 429 HT-QUOTA-001
  内容中跨项目/跨租户资源引用 → 100% 剥离记 refused_policies（AC-068）
  白名单只读工具 query_test_assets（锚定项目 + RBAC）
  → A6 四键：answer / citations / tool_calls / refused_policies
GET  /api/v1/copilot-sessions/{id}                  # 193 仅所有者，messages 最小化
  • L2+ 意图 → 拒绝（copilot_write DISABLED，M4 才开放）；只读工具不改变任何控制流。
  • 无引用的关键事实不得当已核实结论；工具失败要声明无法获取，不猜测。
