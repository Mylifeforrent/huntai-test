2. 三条铁纪律

① 前端不是安全边界：状态机、门禁、配额、聚类、param_hash、幂等键全部后端裁决；前端只渲染 + 提示性校验。
② 不直连外部系统：Jira/GitHub/CI/Release 一律经后端；不持有外部凭证；会话 Cookie 不进 localStorage。
③ 受理 ≠ 完成：收到 202 只显示「受理中」；网络未决先 GET 对账，禁止假定成功/失败。

4. UI 纪律

  • 七态基线：每页覆盖默认/加载/空数据/无结果/错误/无权限/成功——用 QueryGate 统一渲染。
  • 列表筛选/排序/分页必须进 URL（useUrlState），刷新后可还原。
  • SSE 只是 hint：进度条/提示用 SSE，终态/资格一律 GET 对账（「权威状态以 GET 为准」要写在 UI 上）。
  • 等待态（WAITING_APPROVAL / WAITING_EXTERNAL）不因耗时隐藏；风险等级 L0–L4 用色标。
  • 桌面优先：≥1280 全功能；1024–1279 可用；<1024 只读。
