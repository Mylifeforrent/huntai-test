# M2 实现提示 · Web、门禁阻断、集成、Agent 试点

权威：US-04–07、US-13（试点）、US-14（M2 段）、US-06。M2 与 M3 可并行；**Release v1 依赖本里程碑 Jira**。清单见 [ai_context.md](../ai_context.md) §4.3。

## 硬约束

- Playwright **独立于 API 进程**。Agent 结果**不进门禁**、不作发布证据。
- 定位器无自动改写路径；落地走 diff → FR-04 → 快照 → 可回滚。
- 门禁 FAIL 必须影响 CI exit code（反面清单：竞品「只报告不阻断」）。
- 制品正文：M0/M1 本地卷 `object_key` 约定在 M2 仍稳定；**不要**本切片启用 MinIO 产品面（ADR 0009：MinIO 为 M2+ **且**须另走启用前置 + change_log）。
- Agent 终止信号必须服务端持久化（多 worker 可停）——可用 PG，仍不必上 Temporal，除非已单独通过生产 Gate（Q3）。
