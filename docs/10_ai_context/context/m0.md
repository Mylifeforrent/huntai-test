# M0 实现提示 · 基座

权威：`docs/08_prd/prd.md` US-11/12/15/16/19；附录 B.10 M0 Gate。切片清单见 [ai_context.md](../ai_context.md) §4.1。

## 硬约束

- 只实现 `api_spec.md` 已编号端点。ErrorEnvelope；无会话 **401 HT-AUTH-001**，禁止伪装 404。
- 无 JIT：callback 必须命中已有 `users.idp_subject`；0 或 >1 行 → 无组织上下文拒绝。
- LDAP 不做。Cookie 名/TTL/再认证窗口秒数仍 TBD，只经 `.env` 注入，禁止在代码写默认产品秒数。
- M0/M1 禁止启用 Temporal / Redis / MinIO / Vault。TestRun「无永久 running」用 PostgreSQL 状态 + 行锁/定时扫描，不要借机引入 Worker 产品。
- 身份模块禁止 import 审计 ORM；只走 `audit_port`。
- 前端：无登录页（P01–P25 无此项）；401 跳 OIDC；viewer 只读为 UX。
