## 硬约束

- 生成默认**不落库**；保存才 TestCase DRAFT + `ai-generated`。禁止 save 绕过审阅直写 ACTIVE。
- 所有 A1/A2 走 LLM 工厂 + AIInvocationLog（S-M0-06）。
- 变量解析失败必须报错，禁止静默保留原文。
- 受理回执 ≠ TestRun 终态。SSE（API-210/211）只推进度，不是命令通道。
- 引用型用例重放不得重复触发外部 Job（幂等键）。
- 仍禁止 Temporal/MinIO/Redis/Vault。
