## 1. 怎么用

1. 先读仓库根 `AGENTS.md` 与本文件 §2–§4。
2. 按里程碑领取切片 ID（`S-M0-…`）。未完成的 **M0 切片优先于 M1**（PRD：M1 依赖 M0）。
3. 打开对应 `context/mN.md` 与契约正文，按 API / AC 实现；前端页面壳已在 `frontend/`，未开发端点保持「未开发」态，禁止伪造成功。
4. LDAP、MCP、LangGraph、Temporal 启用、MinIO/Redis/Vault **不得**因本拆解提前引入（ADR 0009：M0/M1 单 PostgreSQL）。

## 2. 设计摘要（给代理）

| 主题 | 结论（勿再决策） |
|---|---|
| 产品 | 企业内部 AI 测试平台；编排质量证据，不替代 Jira/GitHub/CI/Release |
| 身份 | OIDC Auth Code + PKCE；服务端可吊销会话；**无 JIT**；无组织上下文拒绝；LDAP 非 M0 必做 |
| 权限 | 每请求 RBAC + 租户过滤；前端置灰不是安全边界 |
| 副作用 | L0–L4 + Policy Gate 四值；未声明动作默认拒绝；四眼；`APPROVED` ≠ 执行成功 |
| 状态 | TestRun 10 态等只在后端迁移；受理回执 ≠ 业务完成 |
| 运行面 M0/M1 | PostgreSQL + API + 前端；幂等键 / CAS / 行锁；禁止启用 Temporal/Redis/MinIO/Vault |
| API | 只实现 `api_spec.md` 已编号端点；ErrorEnvelope；Sess 通道需会话 |
